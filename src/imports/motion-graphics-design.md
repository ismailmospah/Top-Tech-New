Design a modern, high-end website for a Motion Graphics Studio based in Saudi Arabia that provides services such as motion graphics, video production, branding animations, and digital content creation.

The design should feel creative, bold, and premium, targeting businesses, startups, and brands looking for high-quality motion graphics.

Visual Style
	•	Primary color: Purple
	•	Secondary colors: Yellow and White
	•	Purple should dominate the brand identity and main UI elements.
	•	Yellow should be used for call-to-action buttons, highlights, and accents.
	•	White should keep the layout clean and minimal.

Design Direction
	•	Modern startup-style layout
	•	Smooth gradients using purple tones
	•	Large typography and bold headlines
	•	Motion-inspired shapes and abstract graphics
	•	Subtle animations and hover effects
	•	Dark-purple sections mixed with white sections for contrast
	•	Very clean spacing and grid system

Pages / Sections

1. Hero Section
	•	Big headline: “We Turn Ideas Into Motion”
	•	Subheadline explaining the studio services
	•	CTA buttons:
	•	“View Our Work”
	•	“Start Your Project”
	•	Animated abstract motion graphics background

2. Services Section
Cards for:
	•	Motion Graphics
	•	Explainer Videos
	•	Social Media Animations
	•	Branding & Logo Animation
	•	Video Editing

Each card should include:
	•	Icon
	•	Short description
	•	Hover animation

3. Portfolio / Work
Grid layout showing motion graphics projects with preview thumbnails.
Hover interaction that reveals project title and category.

4. Process Section
4 step process:
	1.	Idea
	2.	Storyboard
	3.	Animation
	4.	Delivery

Use creative icons and timeline style layout.

5. Clients / Brands
Logos of companies the studio worked with.

6. Testimonials
Client feedback in modern cards.

7. Call To Action
Bold purple section:
“Let’s Create Something Amazing”
Button: Start a Project

8. Contact Section
	•	Contact form
	•	WhatsApp button
	•	Email
	•	Location: Saudi Arabia

UI Style
	•	Rounded cards
	•	Soft shadows
	•	Smooth micro-interactions
	•	Modern SaaS style
	•	Clean grid layout
	•	Premium feel similar to top creative agencies

Make the design conversion-focused and visually impressive, showcasing the studio as a top creative motion graphics agency in the Saudi market.
